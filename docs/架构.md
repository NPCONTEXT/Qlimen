## 三层 + 安全底座

| 层 | 写什么 | 在哪 | 谁维护 | 加锁 |
|---|---|---|---|---|
| 核心协议 | 用户要什么、什么不能做。用户是同一个人，换哪个模型都成立 | `core/rules/AGENTS.md` | 主模型出 diff，用户批准 | 锁 |
| 私有协议 | 这个模型在这个壳里怎么做到：能力、限制、自己犯过的错、本机的坑 | `~/.claude/private-protocol.md` 等，每个环境一份；示例在 `examples/私有协议/` | 该环境的主模型自己写 | **不锁**：被纠正时要能当场写进去 |
| 工人名册 | 每个工人会什么、多少钱、实绩如何。只记事实，不写「先派谁」 | `core/skills/waibao/` | 主模型 | 不锁 |
| 安全底座 | guard 钩子、派工脚本（目录范围、工人档案、越界审计、账本）、加锁 | `core/workers/`、`core/bin/` | 不常动 | 锁 |

**分层标准**：一条东西写的是「用户要什么」就放核心；写的是「这个模型怎么做到」就放私有；写的是「某个工人怎么样」就放名册。

反例：作者曾把「中转 Opus 没有视觉，看图派工人」写进全局分工表，换成官方 Opus（能看图）后，又得在全局补一条例外。按这个标准，它只该出现在中转 Opus 的私有协议里。

## 安全底座：三道闸，各管一件事

1. **加锁（`qlimen-lock`）**：用 macOS 的 `chflags uchg` 锁住核心协议、派工脚本、钩子配置、各工具入口。加锁后 AI 写这些文件会报 `Operation not permitted`；但沙箱拒写也可能报同样的错，协议要求先分清（`ls -lO <文件>` 有 `uchg` 就是加锁）：是加锁就停下、出 diff、请用户本人运行 `$QLIMEN_HOME/core/bin/qlimen-unlock`；是沙箱就按所在环境的方式申请权限。**防顺手，不防故意**：解锁不需要密码。
2. **guard（PreToolUse 钩子）**：不经 waibao、直接调用 `dsh headless` 或 `kimi -p` 的命令，guard 返回「问」（`ask`），由宿主弹框问用户：Claude Code 和 DSH 里实测会弹框，等用户点允许才执行；Codex 里会不会弹没核实（改成「问」之前返回「拦」时，实测能拦下）。直接调用不记账，也不套工人档案。它只看会执行的部分：单引号里的文字、结束符带引号的 heredoc（`<<'EOF'`）正文、注释不算；双引号和 `<<EOF` 正文里的 `$( )`、反引号会真的执行，照样检查。壳名放进变量这种故意绕的写法不管。
3. **派工脚本（`waibao`）**：
   - 目录必须在 `allow_roots` 里，不能是禁区，也不能是工作区顶层。
   - 工人档案按类型给工具：本地只读的没有联网和命令行，联网的读不了本地；写结果的，业务产物限定写进 `--out` 文件夹（脚本盯着写文件的工具，另有 macOS `sandbox-exec` 兜底），系统沙箱另外放行工人数据目录、临时目录和 `/dev`，这几处是工人进程运行要用的。
   - 工具报警：读到工人调用名单以外的工具、或往结果文件夹以外写的事件后，终止后续运行。读到事件时工具可能已经执行，已发生的副作用撤不回。
   - 回执列出工人读过的工作目录以外的路径：普通越界照常返回；严重越界（禁区、`/tmp`、家目录隐藏目录等）不打印回答，标为不可信。
   - 记账：DeepSeek 按 tokens 估算，Kimi 按次。超了日上限只提醒，不拦（用户批准高于预算）。

**已知不管的**：工人的读文件工具本身不按路径拦，所以越界审计只是事后报告，读到的内容已经发给模型服务商了。这一点在 `adapters/kimi/说明.md` 和工人名册里都写明了。

## 协议怎么起作用

协议本身只是文字，起作用靠三样：

- **模型愿意遵守**。最重要的一条是「诚实」放第一优先级：协议要求没验证就说没验证，不知道就说不确定。作者的观察（主要是 Opus，没有逐条统计）：出了错会停手，说清错在哪、怎么补；DeepSeek flash 也出现过认错递归、改错时又引出新错（见 [实测记录.md](实测记录.md) 第 5 节「已知局限或负面影响」第 9 条）。
- **文件代替记忆**。非一步完成的任务，任务目录里保持「方案 / TODO / 交接」三件套。压缩、换会话、换模型之后，读交接就能接着干。
- **底座兜底**：加锁、guard、派工脚本，管的是「顺手越界」这一类。

## 不在仓库里的

- 作者的自动记忆（Claude Code 的 memory）、各环境的私有协议原件、派工账本和工人结果原文：都是个人数据。私有协议给了脱敏示例。
- 作者自己的几个 skill（历史任务索引、各类业务 skill）。
