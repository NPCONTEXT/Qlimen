# Codex 适配说明

核心（`../../core/`）不依赖 Codex，本目录只写怎么接进去。
作者环境：ChatGPT 桌面应用里的 Codex（命令行 `0.162.0-alpha`，模型 GPT-6.1-sol），2026-10-08 接入。

## 挂载点

| 东西 | 接到 Codex 的哪里 | 方式 |
|---|---|---|
| `core/rules/AGENTS.md` | `~/.codex/AGENTS.md` | 软链接（Codex 会跟随，作者用 `codex debug prompt-input` 核实过） |
| Codex 私有协议 | `~/.codex/private-protocol.md`（实体文件，Codex 自己维护，不锁） | `hooks.json` 的 `SessionStart` 用 `/bin/cat` 送进上下文；起步可以照 `examples/私有协议/codex.md` 改 |
| guard | `~/.codex/hooks.json` 的 `PreToolUse`，matcher `^Bash$` | 钩子 |
| 工人名册 `core/skills/waibao` | `~/.codex/skills/waibao` | 软链接 |

**为什么私有协议要走钩子**：Codex 全局只读 `~/.codex/` 下的一个 `AGENTS.override.md` 或 `AGENTS.md`，不支持 `@` 引用。入口要保持是核心的链接、不建副本（核心 §7），所以私有协议只能从别处送进去。`SessionStart` 不写 matcher 时，新会话、恢复、清空、压缩后都会触发（官方文档的 hooks 页）。

## 手动接入（不用 install.sh 时）

`$QLIMEN_HOME` 指 Qlimen 仓库的绝对路径，`install.sh` 运行时会打印出来；建议在 shell 配置里 export，或直接换成绝对路径。

```bash
mv ~/.codex/AGENTS.md ~/.codex/AGENTS.md.bak 2>/dev/null   # 原来有的话先备份
ln -s "$QLIMEN_HOME/core/rules/AGENTS.md" ~/.codex/AGENTS.md
cp "$QLIMEN_HOME/examples/私有协议/codex.md" ~/.codex/private-protocol.md
mkdir -p ~/.codex/skills && ln -s "$QLIMEN_HOME/core/skills/waibao" ~/.codex/skills/waibao
```

`install.sh --apply` 会用本目录 `hooks.example.json` 生成 `hooks.json`（路径已填好），把它复制成 `~/.codex/hooks.json`；原来就有这个文件的话，手动合并。

## 钩子

| 事件 | 匹配 | 命令 | 作用 | 钩子坏了时 |
|---|---|---|---|---|
| SessionStart | 全部 | `/bin/cat ~/.codex/private-protocol.md` | 把私有协议加进开发者上下文 | Codex 报钩子失败，会话照常 |
| PreToolUse | `^Bash$` | `core/workers/guard` | 不经 waibao、直接调 dsh 无头模式 / `kimi -p` 时问用户 | 放行 |

- 新加的或改过的钩子要先信任才会运行：在 Codex 命令行里用 `/hooks`（官方文档）。信任按钩子定义的哈希记，改私有协议的内容不影响信任，改 `hooks.json` 要重新信任。
- guard 2026-10-09 起返回 `ask`。Codex 接住 `ask` 会不会弹框，作者没核实；在那之前（返回 `deny`），作者在真实会话里实测过能拦下。
- `tests/codex/跑验收.py` 用 Codex 格式的输入测 guard，6 条。

## 装好以后怎么查

- 在一个非 git 目录里运行 `codex debug prompt-input`，看输出里有没有一段 AGENTS 指令、是不是核心全文。
- 注意：`debug prompt-input` 的输出里看不到 `SessionStart` 送进来的内容，不能用它查私有协议。要查，就新开一个会话问它私有协议第一行是什么。
- 新开会话，让它运行 `true || kimi -p hi`（`||` 后面不会真的执行，不调模型），看有没有弹出确认框。别用 `echo "kimi -p hi"` 这类写法测：引号里的纯文字 guard 本来就放行，测不出东西。

## 已知限制

- `~/.codex/AGENTS.override.md` 存在且非空时，Codex 只读它、不读 `AGENTS.md`。这个位置没锁，有人往里写东西，核心协议就被盖住了。
- guard 只看命令文本，和 Claude、DSH 两边一样：防顺手，不防故意。
- Codex 的 exec 模式（被别的模型当工人跑）也会读全局 `AGENTS.md`，于是工人也开始写状态标记、阶段预告，其实用不着。作者的统计见 `docs/实测记录.md`。要避免，就给工人单独的 `CODEX_HOME`。
- 路径都是绝对路径，Qlimen 换了位置，`hooks.json` 和链接都要改。

## 撤掉

`$QLIMEN_HOME/core/bin/qlimen-unlock` → 删掉 `~/.codex/AGENTS.md` 链接，把备份换回来 → 删 `~/.codex/hooks.json` 和 `~/.codex/skills/waibao` → 保护清单删掉 Codex 那两行 → `$QLIMEN_HOME/core/bin/qlimen-lock`。
