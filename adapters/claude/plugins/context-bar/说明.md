# 上下文横条（context-bar）

Claude 桌面应用 Code 会话的插件：显示上下文用量，快满时提醒交接，一键「交接并压缩」，压缩摘要用简体中文写。作者环境：桌面应用 4.4212.0、Claude Code 2.1.309（2026-10）；命令行版 Claude Code 按理也能装，作者没测过。

## 做什么

- **用量横条**：输入框上方一行「上下文 X%（Y 万 / Z 万）」。低于 70% 灰色；70% 起黄色「该准备交接了」；85% 起红色加粗「现在交接」，并弹一次提示（停 15 秒）。用量降回 85% 以下再涨上去，会再弹。会话开始、每次工具调用后、每回合结束、每次压缩后刷新；读用量不花钱。新会话要等第一条回复后才有数字。
- **交接并压缩**（回合进行中隐藏）：点一次只变成「确认交接」和「取消」，5 秒内不点自己复原。点「确认交接」后：
  1. 插件替你发一句交接请求（界面上显示成你的消息，记录里标明是插件发的），让 Claude 照协议写好交接（照 Qlimen 现在的写法，就是更新 TODO 最上面的「现在」、往 `记录.md` 追加），回复最后一行写「交接完成」；
  2. 回合结束后排队运行 `/compact`（会话空闲了才执行，和你手动输入 `/compact` 走同一条路）。
  最后一行不是「交接完成」、被打断或出错，都不压缩，弹「没压缩：……」。
- **中文摘要**：每次压缩（手动、自动、预先计算）都附上摘要要求：用简体中文写，第一行是「【压缩后提醒】……」，保留用户原话、停点和下一步、任务目录路径、还在跑的后台任务。子代理自己的压缩不改。
- **压缩完**：先显示灰字「上下文：刚压缩完，下一条回复后更新」，按钮隐藏；出现新的请求、数字变了再恢复。
- 和建议插件（`../suggest-bar/`）共用输入框上方这一块：上下文这一行在上，建议那一行紧贴输入框。

## 装

复制整个文件夹到 `~/.claude/skills/context-bar/`，新开的会话自动加载（作者实测）。放软链接能不能加载，没测过。

```bash
mkdir -p ~/.claude/skills && cp -R "$QLIMEN_HOME/adapters/claude/plugins/context-bar" ~/.claude/skills/context-bar
```

`$QLIMEN_HOME` 指你放 Qlimen 仓库的绝对路径（`install.sh` 运行时会打印出来），没设这个变量就直接换成路径。

已经开着的会话，要等它的进程重启才加载。

建议同时在项目根目录 `CLAUDE.md` 末尾加一段 `## Compact Instructions`，写同样的摘要要求（`hooks/register.tsx` 里的 `ZH_INSTRUCTIONS`）。程序自带的压缩提示词会照上下文里这类要求做，插件没加载时也管用。

## 改、测、关

- 变色的百分比：`hooks/register.tsx` 顶部的 `WARN`、`DANGER`。摘要要求：`ZH_INSTRUCTIONS`（和 `CLAUDE.md` 那段一起改）。按钮发的话：`HANDOFF_PROMPT`，结束标记是 `DONE`（「交接完成」）。改完新开会话生效。
- 测试 25 个，测试里的用量、模型、命令都是假的，不花钱：`claude plugin test <插件文件夹>`；校验：`claude plugin validate <插件文件夹>`（会提醒没有图标，那只跟提交到官方插件目录有关）。桌面应用没装命令行版时，用应用自带的那一份：`~/Library/Application Support/Claude/claude-code/<版本>/<哈希>/claude.app/Contents/MacOS/claude`，路径随应用升级会变。
- 关掉：把 `~/.claude/skills/context-bar/` 移走，新开的会话就没有了；`CLAUDE.md` 那段另删。

## 已知限制

- 百分比按模型的整个上下文窗口算；设了 `autoCompactWindow` 之后，百分比就不代表离自动压缩还有多远。
- 横条显示的是上一次请求的大小，要等下一条回复才更新。新会话一开始的几个百分点是系统提示、工具、记忆这些固定内容，压缩减不掉。
- 自动压缩不拦，仍在官方的阈值触发。
- 按钮用 `$.command.run` 排队运行 `/compact`：`$.session.compact` 不排队、回合没彻底结束就拒绝（作者 10-18 实测三次全被拒）。
