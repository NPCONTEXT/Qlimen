# 建议横条（suggest-bar）

Claude 桌面应用 Code 会话的插件：每轮回复完后，用模型猜你的下一句，显示在输入框上方，点一下填进输入框或直接发送。它是官方灰字建议（Prompt suggestions）的平替。

开源版从作者在用的 0.3.1 拆出来：去掉了作者自己做对比用的功能（认 Tab、记原生建议、使用记录），**只猜、不记**：不读输入框和剪贴板，不写使用记录；插件只存一个 `/suggest off|on` 的开关，放在 Claude Code 给插件的跨会话存储里。作者环境：桌面应用 4.4212.0、Claude Code 2.1.309（2026-10）。

## 先看：灰字建议的两条路

桌面应用里，官方的灰字建议时有时无（GitHub 上的 [anthropics/claude-code#88391](https://github.com/anthropics/claude-code/issues/88391)，2026-10-30 还开着）。两条路可以同时走：

1. **恢复原生建议**：禁用应用的任务清单工具（原生 TODO），会话不挂任务框，原生灰字就回来了。做法和限制见 [桌面应用.md](../../桌面应用.md)「灰字建议的两条路」。
2. **装这个插件兜底**：哪天官方又改掉建议上屏的机制，这一行建议照样在。

## 做什么

- **三档**：
  - 收起（新会话默认）：后台照猜，输入框上方只有一个「建议 ▾」按钮（装了上下文横条时，在上下文那一行最前面）。猜出新建议时，字变正常色、外面一圈蓝框；没有时字淡、框透明。
  - 展开：点「建议 ▾」，建议那一行出现在输入框上方，右边是「填入」「直接发送」。还没猜出来时显示「正在猜下一句…」，没有建议时显示「暂时没有建议」。再点「建议 ▴」收回。展开、收起只管当前会话。
  - 完全关闭：输入框打 `/suggest off`，所有会话（包括之后新开的）都不猜、不花额度，按钮消失。`/suggest on` 打开，`/suggest` 看现在开没开。
- **两个按钮**：「填入」填进输入框，可以改了再发；「直接发送」当成你的消息直接发出去。
- **不猜的时候**：后台通知、续跑这类不是你打字开启的回合；子代理的回合；被打断的回合。你下一句已经发了，没猜完的旧建议不再显示。
- **清洗**：只取第一行。「无」、空、超过 40 字、像助手口吻的（「我来……」「让我……」）不显示。Opus 偶尔带的乱码开头、`[[…]]`、乱码符号「�」会去掉。整句只有一个字的，除了字母、数字和「好行对嗯是可跑批过停改删」，都不显示。

## 花费

开着时每轮调一次模型（默认 Opus，思考最低，输出上限 300 token），走你的 Claude 额度；交白卷时多问一次。作者 10-27 的对照测试里，平均读 918、写 61 token，约 3 秒。完全关闭时不花。

为什么默认 Opus：作者 10-27 从一周的会话记录里挑了 30 个样本盲评，有效率（能直接用 + 方向对）Opus 43%、Haiku 20%。想省额度，把 `hooks/register.tsx` 里的 `MODEL` 换成 `'haiku'`。

## 装

复制整个文件夹到 `~/.claude/skills/suggest-bar/`，新开的会话自动加载（作者实测）。放软链接能不能加载，没测过。

```bash
mkdir -p ~/.claude/skills && cp -R "$QLIMEN_HOME/adapters/claude/plugins/suggest-bar" ~/.claude/skills/suggest-bar
```

`$QLIMEN_HOME` 指你放 Qlimen 仓库的绝对路径（`install.sh` 运行时会打印出来），没设这个变量就直接换成路径。

和上下文横条（`../context-bar/`）一起装时，两个共用输入框上方那一块：收起时「建议」按钮在上下文那一行最前面；展开时上下文在上，建议那一行紧贴输入框。

## 改、测、关

- 提示词、模型、清洗规则：`hooks/register.tsx` 顶部的常量（`SYSTEM`、`MODEL`、`MAX_LEN`、`CLAUDE_VOICE`、`JUNK_HEAD`、`JUNK_ANY`、`BAD_CHAR`、`ONE_CHAR_OK`）。改完新开会话生效。
- 测试 29 个，模型、输入框、存储都是假的，不花钱：`claude plugin test <插件文件夹>`；校验：`claude plugin validate <插件文件夹>`（会提醒没有图标，那只跟提交到官方插件目录有关）。桌面应用没装命令行版时，用应用自带的那一份，路径见上下文横条的说明。
- 只是不想看：保持收起（默认）。不想花额度：`/suggest off`。彻底拿掉：把 `~/.claude/skills/suggest-bar/` 移走，新开的会话就没有了。

## 已知限制

- 插件截不到 Tab，不能像原生建议那样按 Tab 采用，只能点按钮。
- 桌面上的按钮是系统按钮，里面的字设不了颜色，只能靠变淡和外面的框。
- Opus 偶尔在句首多出一个怪字（比如「覺好……」），清洗挡不住。
- 改插件文件后，插件会重新加载，正在猜的那一轮会丢。
