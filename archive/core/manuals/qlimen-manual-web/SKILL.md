# 工具与网站

## 什么时候用我
产出是能打开、能用的网页或工具。已有维护说明书的项目（`维护说明书.md`）先读它，以它为准。
来源：几个网站和网页工具（2026-09～10）。

## 调研清单
1. 项目里的 `维护说明书.md` / `交接.md` / `TODO.md` / `README`；有就按它干
2. 现有技术栈与检查命令：`package.json` 的 scripts（`check`、`build`、`lint`）、镜像源
3. 用户定过的版式和保留项（例：信息完整 > 进度条对比 > 紧凑 > 美观；名字不许省略号；引导气泡不许删）
4. 用户的真实数据在哪：**试用/测试不得连用户真实数据文件**，先复制一份
5. 部署方式：谁上传、要不要密码（要密码就由用户执行）

## 方案必写
- 改版不删用户已有的功能/引导，只改样式；要删先问
- 测哪些宽度/设备（例：1440/1024/375，手机微信/Safari 需用户真机）
- 交付给非技术用户的启动方式（双击 `.command` 之类），不是「运行 npm start」

## 验收清单（挑用）
- [ ] cmd: npm run build
- [ ] cmd: npx eslint .
- [ ] cmd: npm run check　　（项目有就用）
- [ ] file: <交付目录>/index.html
- [ ] url: <线上地址>　　（上线后）
- [ ] manual: 浏览器直开深链接（如 /model/xxx 刷新）不白屏
- [ ] manual: 用户真机试一次关键操作

## 坑（都踩过）
- curl 只验 HTML 状态码，测不出深链接白屏（Vite `base` 写成 `'./'` 会 404 资源）；要浏览器直开验证
- http 站点没有 `navigator.clipboard` / `share`，要 textarea+execCommand 回退
- 微信/App 内长按保存图片读不到 `blob:`，预览图用 data URL；海报用 Canvas 画，不截 DOM
- 存档：`localStorage.setItem` 包 try；读不出来时原文另存隔离，不静默覆盖
- 别为单行布局给进度条固定窄宽；放不下就换行
- 镜像源改回内网域名会导致公网装不上依赖
- TypeScript 严格模式下不用 any 绕报错
- `rm -rf` 对不存在路径不报错，删完 `ls` 确认；带变量写成 `"${X:?}/…"`
- 命令里别把含反引号的中文放进双引号；写文件用编辑工具
- 画图类界面（关系图、连线）测试要量位置：线端点和图形中心的屏幕坐标差几像素；只测「点得中」抓不到点线错位（2026-10，一个关系图工具）
- 旧 tailwind base 把 svg 设成 display:block，`text-align:center` 不再居中；图标居中显式写 flex
