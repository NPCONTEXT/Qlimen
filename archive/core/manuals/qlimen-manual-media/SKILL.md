# 音视频与动画

## 什么时候用我
产出是视频、音频或动画。
来源：一部写实短片（Blender + 云 GPU 渲染）、一支 MV（three.js + 无头 Chrome + ffmpeg）（2026-09～10）。

## 调研清单
1. 用户定的硬约束：时长、风格、是否允许 AI 视频模型（例：有一部短片用户定了只用代码渲染 + 传统工具）
2. 本机环境：`ffmpeg`、`ffprobe`、Node、Chrome、字体、Python 库——只读检查，缺的列出来问
3. 素材与分轨：歌曲、歌词、人声/鼓分轨（有分轨卡点准得多）
4. 算力：先做 10 秒渲染测速，再按实测报全片耗时；>10 分钟重计算按 AGENTS 比较本机 vs 云端
5. 存放位置：开了云盘同步的目录（如 iCloud 同步的 `~/Documents`）不放几 GB 的渲染结果和私钥

## 方案必写
- 分镜表（镜号、拍、画面、字）和卡点机制；卡点目标（例：切点与节拍偏差 < 1 帧）
- 渲染管线每一段的状态：已验证 / 只做语法检查 / 没跑过
- 云端：开机、关机、充值由用户做；按小时计费写上限；实例内关机要用户同意

## 验收清单（挑用）
- [ ] media: <成片>.mp4 duration <下限>-<上限>
- [ ] file: <卡点对照图>.png
- [ ] dir: <抽帧目录> >= <镜头数>
- [ ] manual: 用户看成片验收
- [ ] manual: 用户试听配乐（模型听不了音频）

## 坑（都踩过）
- 模型不能试听：配乐只能做电平/节拍数值检查，听感必须用户确认
- 每段做完就抽帧自查，别等全片渲染完才看
- 全片逐帧扫相邻帧差异，能发现花屏、跳帧、物体飞出画面
- 渲染驱动要原子写帧、跳过已有帧，支持断点续跑
- 云端跑完要确认实例真的关了（让用户看控制台），并提醒清理公钥、释放克隆实例
- 用户额度紧时不要开子代理审片
- 中间文件（EXR 等）在用户验收前保留，删除要用户明确说
